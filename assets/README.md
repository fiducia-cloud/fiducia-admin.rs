# assets — vendored browser scripts

Static JavaScript served same-origin by the app (no CDN, no bundler at runtime).
Each file is `include_str!`-compiled into the binary in `main.rs` and served at
`/assets/…`, so the single binary ships everything the browser needs and the
offline E2E works without a network round-trip or a third-party trust boundary.

- **`htmx.min.js`** — the vendored htmx library (minified, third-party). Powers
  the `hx-*` progressive-enhancement attributes in the rendered pages. Do not
  hand-edit; replace by re-vendoring the upstream release.
- **`fiducia-sync.js`** — the first-party, self-contained `@fiducia/sync` admin
  browser bundle (wasm inlined). Boots the local-first sync client on pages that
  declare `data-fiducia-sync` tables (opens IndexedDB, subscribes `/admin/ws`).
  Generated by `fiducia-sync/sdk: npm run build:admin-bundle`.
